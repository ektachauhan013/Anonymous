# Bill Calculator

A simple shop billing application that generates an itemized bill based on the quantities entered by the customer.

## Menu

| Item | Price |
|---|---:|
| Samosa | ₹15 |
| Tea | ₹10 |
| Burger | ₹25 |

## Features

- Displays the available menu and item prices.
- Accepts quantities for individual items.
- Calculates the cost of each item.
- Displays an itemized bill with quantity, unit price, and total cost.
- Calculates the final bill amount.

## Technologies Used

- HTML5
- CSS3
- JavaScript
