# Counter

A basic interactive counter built with JavaScript. Users can change the displayed number through button clicks.

## Features

- Initializes the counter at 0.
- Increases the current value.
- Decreases the current value.
- Resets the value to 0.
- Updates the displayed number after each operation.

## JavaScript Functions

|  Function    | Purpose                             |
|  Show()      | Displays the current counter value. |
|  increase()  | Increments the value by one.        |
|  decrease()  | Decrements the value by one.        |
|  reset()     | Sets the value back to zero.        |

The application uses JavaScript event listeners to connect button clicks to the corresponding functions.

## Technologies Used

- HTML5
- CSS3
- JavaScript
